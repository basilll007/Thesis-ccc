Methods

What the pipeline actually does

Six deterministic steps, run end-to-end by src/run_prototype.py with a fixed random seed, from raw Xenium output to a ranked interaction table and figures.

1

Load & harmonize

Read the Xenium cell_feature_matrix.h5 into AnnData; join cells.csv centroids as spatial coordinates.

10x Xeniumx/y centroid
2

Quality control

Filter low-count cells and rarely-detected genes before any downstream inference.

min_counts=10min_cells=3
3

Normalize & cluster

Total-count normalize, log1p transform, PCA, neighbor graph, then Leiden community detection.

target_sum=1e4resolution=0.5seed=42
4

Cell-type annotation

Coarse marker-score labeling (epithelial, immune, endothelial, fibroblast) via mean marker-gene expression per cell.

EPCAM/KRT…PTPRC/CD74…PECAM1/VWF…COL1A1/DCN…
5

Spatial neighbor graph

Build a proximity graph over cell centroids with Squidpy so downstream scoring is spatially aware.

coord_type=genericn_neighs=6
6

Baseline L–R scoring

Score a curated 20-pair ligand–receptor panel per sender→receiver cell-type pair with squidpy.gr.ligrec, then export CSV, AnnData, figures and a run log.

n_perms=1 (smoke test)seed=42
⚠️

Scope note. This is infrastructure plus a baseline model — proximity + co-expression is plausible evidence of communication, not proof of a functional response. The single-permutation p-values below are a smoke-test artifact, not calibrated significance. See docs/PROJECT_CONTEXT.md.

Progress

What's been carried out vs. what's next

v0 is deliberately scoped to infrastructure + a baseline model. The thesis contribution — a minimal, high-confidence communication network with calibrated uncertainty — is future work.

Carried out (v0) done

  • ✅ Public dataset acquired & provenance logged

    10x Genomics Xenium V1 human breast, 2-FOV bundle; CC BY 4.0; SHA-256 verified, size and date recorded.

  • ✅ Reproducible environment

    Pinned conda/uv environment, Python 3.11, fixed random seed 42 throughout.

  • ✅ QC, clustering & annotation

    Count filtering, normalization, Leiden clustering (res. 0.5), coarse marker-based cell typing.

  • ✅ Spatial neighbor graph

    Squidpy generic-coordinate graph, 6 nearest neighbors per cell.

  • ✅ Baseline L–R ranking

    squidpy.gr.ligrec over a curated 20-pair panel; ranked CSV, figures and run log exported.

Next steps planned

  • 🧪 Functional-response evidence

    Corroborate inferred signaling with a downstream transcriptional response in receiver cells, not just proximity + co-expression.

  • 🎯 Reproducibility calibration

    Re-run with a full permutation budget and quantify which interactions replicate across multiple patient samples, with calibrated uncertainty.

  • 🌐 Spatial Prize-Collecting Steiner Tree

    Graph optimization to select a minimal, high-confidence communication subnetwork consistent with prior pathway knowledge, instead of the full unstable candidate set.

  • 🔬 Optional perturbation cross-check

    Use external perturbation data only as a secondary validation signal — never the core method.
