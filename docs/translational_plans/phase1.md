## Reproduction gate
Read the exact v3 gene lists from its source. Recompute slide medians from saved spot scores, aggregate using the original patient x site equal-slide means then equal-site metastatic means and invoke the original pure compare function. Require agreement with the saved hypoxia median paired effect, 13 pairs, exact p and five-program BH q (absolute tolerance 1e-12). Also rescore hypoxia from all included raw matrices and compare spot scores within float32 tolerance 1e-6. If either check fails, BLOCK Phase 1 without testing sensitivities. Preserve the discrepancy.

## Prespecified analyses
All scores otherwise use v3 normalize_total(1e4), log1p and Scanpy 1.10.3 score_genes, seed 42, ctrl_size=50 per bin, 25 bins, ctrl_as_ref=True and use_raw=False. Program needs >=5 present genes. Keep original slide QC and PDX exclusion unless replaced by the stricter depth rule below. Aggregate slide medians, then patient x anatomical site equal-slide means; average metastatic anatomical sites equally within each patient. Two-sided paired exact Wilcoxon with exhaustive sign permutations, rounding differences to 12 decimals, no add-one adjustment. Report n paired patients and all dropped slides. At least 5 pairs required to judge a sensitivity; fewer means inconclusive, not robust.

a. Exclude every inferred CytAssist slide, retain all other original QC-passing slides.
b. Select the top tercile (>=within-slide 2/3 quantile) of mean log-normalised KRT19/KRT7/EPCAM, using at least 2 present genes. Exclude high host-tissue-marker spots: positive mean marker score strictly above the within-slide 90th percentile. Analyst-declared proxy panels: primary pancreas PRSS1 CPA1 PNLIP AMY2A; liver ALB APOA1 APOA2 TTR; lung SFTPA1 SFTPA2 SFTPB SFTPC SCGB1A1; peritoneum UPK3B CALB2 WT1 MSLN. These are screening proxies, not validated tumour annotations; peritoneal markers can overlap tumour biology. Require >=50 selected spots per slide and >=2 host markers present, otherwise drop/report that slide. Select using these proxy scores only, before examining hypoxia.
c. Common depth 2,000 UMIs per spot. Start from raw matrices, drop a human slide if >50% of original spots have <2,000 UMIs; retain only spots >=2,000. Sample exactly 2,000 molecules without replacement per retained spot, seed 42 per slide. Thus every retained slide's median is exactly 2,000. Then apply the unchanged normalisation and score. Report every dropped slide.
d. Leave one of each of the 12 v3 hypoxia genes out (12 scores) and use the separately curated human MSigDB HALLMARK_HYPOXIA membership from the public page https://www.gsea-msigdb.org/gsea/msigdb/human/geneset/HALLMARK_HYPOXIA.html (opened before this plan; source publication PMID 26771021, Liberzon et al.). Obtain the displayed members without bypassing login or blocks. Save full member list and overlap. It is an independently curated set, not guaranteed disjoint. If unavailable, mark that check BLOCKED/UNVERIFIED; do not invent membership.
e. Primary versus each metastatic organ, paired differences and n only; descriptive, no new organ-specific significance claims.
f. Generate 1,000 distinct random signatures of size 12 matched to the original hypoxia genes on equal-slide mean log-normalised expression. Universe: exact gene symbols shared by all included human slides, average expression >0.01; exclude the original 12 hypoxia genes from controls. Use 25 rank-quantile bins (deterministic symbol tie order); for each original gene draw without replacement within its bin, seed 42. Use the same slide-specific matched-control scoring procedure as the observed signature. Report median paired effect for all 1,000 sets, positive-tail add-one empirical p=(1+#random effects >= observed)/1001, and empirical percentile. Do not treat spots or the random sets as biological replicates. Random-set matching does not match cell type or host organ.

## Decision rule
ROBUST only if median paired effect >0 in a,b,c, every leave-one-gene-out and the independent gene set, and paired p<0.05 in a,b,c. If any adequately testable required check fails: NOT ROBUST, naming it. Missing membership, failed reproduction or insufficient pairs: INCONCLUSIVE (with failed testable checks still reported). f is contextual and not an additional gate. Report raw p for planned sensitivities and BH across a,b,c as secondary, not a substitute for the declared raw-p rule. One composite PNG/PDF figure. No causal, physiological or clinical claims.
