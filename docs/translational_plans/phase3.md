# Phase 3: predeclared bulk signature-survival associations

Commit before signature/outcome models. Reuse verbatim the five v3 program gene lists from src/pdac/v3_phase5_programs.py (CAF, EMT, Hypoxia, Interferon, Immune_infiltration). T-cell proxy: CD3D CD3E CD3G CD2 TRAC CD8A CD4 IL7R CD247. Immune_exclusion_proxy = CAF score minus T-cell proxy score. These analyst-declared expression proxies are not functional immune exclusion assays.

For verified nonnegative RSEM linear expression, log2(x+1); if metadata states already-log2 expression, use unchanged and record it. Average duplicate gene-symbol expression rows before the log transformation. One sample per patient. In each analysis cohort, standardise each gene to across-patient mean 0, sample SD 1; exclude zero-variance genes. Signature = mean gene z-score, requiring >=5 genes and >=50% declared coverage; standardise each final signature to sample SD 1 for HR per SD. Proxy computed from the two component mean-z scores then standardised. Export membership and coverage. No data-derived gene selection or outcome-based tuning.

Primary inference is confirmed-PDAC cohort. If curation is uncertain, run all-primary and strict histology-filtered as planned Phase 2. Fit each of six signatures separately: (i) unadjusted Cox OS ~ signature; (ii) signature + age in decades + sex + stage (I vs II vs III/IV); (iii) additionally purity as fraction. Sex unknown, stage unknown and missing numeric covariates are complete-case exclusions, reported per model. No grade/treatment tuning. Report HR, 95% CI, Wald p, n and events. Minimum 10 events per fitted coefficient and full-rank design; otherwise model BLOCKED with reason, do not simplify post-hoc. BH across six signatures separately per cohort/model family (18 planned primary models); all-primary sensitivity separate BH family. No PH-dependent model shopping.

Check proportional hazards by Schoenfeld residuals correlated with ranked event time using the Grambsch-Therneau score-test variance form; report signature-level and covariate tests, with BH across all PH tests per cohort/model family. Also plot residual trend. If the installed survival library provides a vetted PH test use that exact implementation; if not, clearly label the independently implemented diagnostic and validate it on synthetic null/time-varying examples before use. A PH failure makes constant-HR interpretation exploratory, not confirmatory.

Kaplan-Meier curves: high > cohort median versus low <= median, descriptive, no optimised cutpoints and no extra inferential log-rank tests. Export all curve steps and at-risk counts. Correlation: Spearman signatures vs purity and inter-signature correlations, all pair n; call mostly-a-purity-proxy if |rho|>=0.7, otherwise report the observed rho without a binary claim. Purity estimates can be uncertain and adjustment does not establish intrinsic biology. If second cohort obtained, apply identical gene lists, scoring and model families unchanged, report same-direction yes/no; no tuning.

One composite PNG/PDF figure with six KM panels plus HR/purity diagnostics. Results are prognostic expression associations, not causal effects, clinical recommendations or external validation of a spatial mechanism. A signature relates to survival after adjustment only if the purity+age+sex+stage model is estimable and BH q<0.05, with PH status disclosed. If none pass report the negative result; if final models cannot be fit report that question inconclusive/BLOCKED.
