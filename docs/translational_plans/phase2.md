# Phase 2: public bulk PDAC cohort acquisition and vetting

Commit before downloads or cohort analyses. Preferred TCGA-PAAD cBioPortal PanCancer Atlas processed RNA-seq RSEM matrix with patient/sample clinical files. Open original metadata, data terms/licence, expression metadata and study publication/source links. Public files only; TLS verified. Record every successful and blocked URL, SHA-256 and bytes; no CAPTCHA or HTTP 403/429 bypass. Raw downloads only in F:/Thesis/data/tcga, never Git.

Read actual sample/histology fields before defining membership. Prefer the published 150-PDAC curated list from TCGA 2017 (doi 10.1016/j.ccell.2017.07.007) if its actual identifiers are accessible; otherwise exact clinical histology/OncoTree field explicitly identifying ductal adenocarcinoma. Exclude neuroendocrine, acinar, unspecified pancreas and non-primary samples from confirmed-PDAC analysis. If histology has incomplete verification, report all-primary and strictly histology-filtered cohorts in parallel, never call unknown histology confirmed. One primary RNA sample per patient, lexicographically first barcode if duplicates; record exclusions. Do not infer histology from expression or survival.

Overall survival: source OS_MONTHS and 1:DECEASED / 0:LIVING, or explicitly documented equivalent days and vital status. Keep only finite time >0 and event 0/1. Extract age, sex, AJCC stage, grade; do not silently impute missing clinical data. Tumour purity: prefer published ABSOLUTE/PanCancer purity or verified pathology purity supplied in clinical fields; record units and source, do not relabel expression scores as physical purity. If no verified estimate is accessible, mark purity-adjusted survival BLOCKED instead of substituting an unvalidated score. Cohort table per membership: n patients, n events, median observed OS time and reverse Kaplan-Meier median follow-up; distinguish these. Missingness table for every covariate. Vetting CSV records verified sample counts, data type, available clinical fields, exact access terms and citation requirements. A second public PDAC RNA-seq+OS cohort is optional: use only if access and histology can be verified without changing methods. One cohort/QC composite PNG/PDF figure, including a BLOCKED panel if necessary.

## Verified-field execution resolution (before cohort analysis)
The curated TCGA 2017 Table S1 download encountered CAPTCHA; no bypass is attempted. Use the clinical ICD_O_3_HISTOLOGY field: exactly 8500/3 is the strict ductal subset, supported by the opened NCI morphology table; retain all-primary sensitivity. Do not treat the universal OncoTree PAAD label as ductal verification. GDC ABSOLUTE purity array barcodes match sample identifiers (first 15 TCGA barcode characters). Average multiple called ABSOLUTE aliquots per array, requiring numeric 0<=purity<=1. CPTAC is available: exact HISTOLOGY_DIAGNOSIS=Pancreatic Ductal Adenocarcinoma is strict; all tumours are sensitivity. Its metadata explicitly states already-log2 upper-quartile RSEM, so no second log is taken. Endpoint uses FOLLOW_UP_DAYS and Living/Deceased vital status, converted to months with 365.25/12 days; uniformly require >0 months, not the source article's separate 30-day perioperative exclusion. CPTAC pathology NEOPLASTIC_CELLULARITY can contain semicolon-separated review values; use their arithmetic mean divided by 100, treating them as percentage-style cellularity (inferred scale from clinical ranges and histology description). Record this assumption; it is not ABSOLUTE or an expression-derived estimate. Grade is unavailable for CPTAC and is reported missing.
